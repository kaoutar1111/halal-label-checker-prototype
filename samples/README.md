# Sample Images Directory

This directory contains sample food label images for testing the Halal Label Checker.

## Usage

Place your test images here and they will be available for testing the OCR and matching functionality.

## Recommended Image Specifications

- Format: JPG, PNG, or BMP
- Resolution: At least 800px width recommended
- Lighting: Clear, well-lit photos produce better OCR results
- Focus: Sharp, in-focus images work best

## Sample Labels to Test

1. **English labels**: Common in many countries
2. **French labels**: Common in France and French-speaking regions
3. **Arabic labels**: Common in Middle Eastern countries
4. **Chinese labels**: Common in China and Chinese-speaking regions
